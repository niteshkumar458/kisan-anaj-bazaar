Kisan Anaj Bazaar

🌾 Kisan Anaj Bazaar is an online marketplace for buying and selling agricultural crops and grains.

Features

- 🌾 Farmers can list their products
- 🔎 Product search
- 🛒 Shopping cart
- 📦 Order system
- 🏷️ Product categories
- 📱 Mobile-friendly website

Project

Kisan Anaj Bazaar connects farmers and buyers through a simple online marketplace.

More features such as Firebase database, image upload, user accounts and UPI payment will be added.
